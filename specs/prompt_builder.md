# SPEC: Prompt Builder

## Роль

Переводит состояние игры в **промпт для LLM** и **манифест** для валидатора. Не вызывает LLM, не валидирует. Для `UNKNOWN` не вызывается.

## Контракт

```
build(command, outcome, projection, canon, recent_events, turn, config) -> (prompt: string, manifest: Manifest)
```

`Manifest` (см. `ARCHITECTURE.md` §3.3): `allowed_names`, `allowed_numbers`, `mode`, `verb`, `reason_code`.

При переполнении после всех усечений — `BuildError` (сессия переходит к шаблону, `WARNING`).

## Четыре блока

Порядок фиксирован: `[SYSTEM] → [SCENE] → [RECENT] → [THIS TURN] → [TASK]`.

### Блок 1. SYSTEM (~300 токенов, не усекается)

- Роль, стиль, запреты (см. `DECISIONS.md` D-30, D-33).
- Параметр режима: `look` — «Опиши сцену, которую видит игрок»; `describe` — «Опиши, что произошло».
- Если не влезает — ошибка конфигурации, не рантайма.

### Блок 2. SCENE (~400 токенов, усекается)

Ядро (всегда): название и описание локации; кто здесь (NPC); что здесь лежит (предметы, с количеством); `use_targets` здесь; инвентарь кратко (если не пуст).

Расширения по глаголу:

| Глагол | Добавляется |
|---|---|
| LOOK | — (сцена и есть предмет) |
| GO | «Откуда: {локация}» + направление |
| TAKE / DROP | имя предмета, количество до/после |
| TALK | имя NPC, тема, canon `response` (если есть) |
| USE | имя предмета, имя цели, canon `response` (если есть) |

### Блок 3. RECENT (~400 токенов, усекается первым)

Последние 3–5 **публичных** ходов. Одна строка на ход: номер, глагол, ключевые сущности, результат одной фразой. Провалы — «не удалось». `UNKNOWN` — не включается. Флаги и `reason_code` — не упоминаются.

### Блок 4. THIS TURN (~150 токенов, не усекается)

- `raw` игрока (как написал).
- `result` + `reason_code`, переведённый в наблюдаемое описание (таблица перевода — в сборщике).
- `applied` → наблюдаемые дельты (см. таблицу ниже).
- canon-текст (`response` / `response_on_fail`) как факт.

**Перевод `applied` в дельты:**

| Примитив | Что видит нарратор |
|---|---|
| `add_to_inventory` | «получен {item}» |
| `remove_from_inventory` | «отдан/потрачен {item}» |
| `add_to_location` | «{item} остаётся здесь» |
| `remove_from_location` | «{item} исчезает отсюда» |
| `set_flag` | **ничего** (в MVP все наблюдаемые изменения покрыты перемещениями и canon-текстом) |
| `change_location` | «игрок переместился в {локация}» |

Правило: если изменение нельзя увидеть из этой локации — его нет в промпте.

### Блок 5. TASK (~50 токенов, дублирует SYSTEM)

Одна фраза: «Опиши это в 2–4 предложениях».

## Манифест

Собирается по ходу сборки блоков.

- `allowed_names`: все имена сущностей, попавшие **в любой блок** (scene, recent, this turn, canon-текст). Нормализованные (lowercase, ё→е).
- `allowed_numbers`: содержательные числа из scene и this turn (количества предметов, характеристики). **Номера ходов не входят.**
- `mode`: `look` или `describe`.
- `verb`, `reason_code`: для контекста.

## Бюджеты и усечение

| Блок | Бюджет | Усекается |
|---|---|---|
| SYSTEM | ~300 | нет |
| SCENE | ~400 | да |
| RECENT | ~400 | да, первым |
| THIS TURN | ~150 | нет |
| TASK | ~50 | нет |

Порядок: RECENT от старых к новым до минимума 3 → SCENE (длинные описания → нерелевантные сущности → инвентарь) → если не влезает, `BuildError`.

Оценка токенов: `len(text) / 3` (консервативно для русского).

## Тесты

| # | Сценарий | Ожидание |
|---|---|---|
| PB-1 | Промпт для каждого из 6 глаголов | собирается, все 5 блоков на месте |
| PB-2 | LOOK-режим | `mode=look`, акцент на сцене |
| PB-3 | Приватные события в логе | не попадают в промпт |
| PB-4 | Имена флагов, `reason_code` | не попадают в промпт (grep) |
| PB-5 | Манифест: `allowed_names` содержит все имена из промпта | сверка |
| PB-6 | Манифест: `allowed_numbers` не содержит номеров ходов | проверка |
| PB-7 | Длинный `recent` (10 событий) | усечение до ≥3 |
| PB-8 | Длинное описание локации | усечение до первого предложения |
| PB-9 | Переполнение после всех усечений | `BuildError`, не тихая деградация |
| PB-10 | `set_flag` в `applied` | в промпте нет упоминания флага |
| PB-11 | Replay того же хода | идентичный промпт |
| PB-12 | LOOK: `{scene}` не используется в промпте (это шаблонный слот) | проверка |

## Известные ограничения

- Оценка токенов приблизительная (символы / 3). Точный токенайзер — за пределами MVP.
- `set_flag` скрыт всегда; если появится флаг с наблюдаемым эффектом (например, «свет включён»), понадобится поле в каноне.
