# SPEC: CLI Interface

## Роль

Самый тонкий слой. `read → session.step() → write`. Не принимает решений, не знает про `rung` / проекцию / флаги.

## Контракт с сессией

Использует только публичный интерфейс `Game Session` (см. `specs/session.md`): `start`, `step`, `save`, `load`, `history`. `TurnResult` — четыре поля.

## Цикл

1. Показать `> `.
2. Прочитать строку из stdin.
3. Проверить на мета-команду (точное совпадение, регистронезависимо, **до** сессии).
4. Если не мета — `session.step(raw)`.
5. Показать `TurnResult.text`.
6. Проверить `game_finished` / `aborted`, вернуться или выйти.

## Мета-команды

| Команда | Действие |
|---|---|
| `save` | `session.save(./save.jsonl)`. Если файл есть — подтверждение `Перезаписать? y/n`. |
| `load` | `Session.load(./save.jsonl)` → новая сессия. Если есть несохранённые ходы — подтверждение. |
| `history` | `session.history()` — список `final_text` с номерами. |
| `quit` | выход. |

Фиксированный путь сейва. Мета-команды не идут в `step`.

## Отображение

- `rung=3` — **молча**, без пометок. Игрок не видит, что был шаблон.
- `aborted` — явно: «Сессия прервана из-за внутренней ошибки. Прогресс сохранён до последнего успешного хода.»
- `game_finished` — показать `text` финального хода, затем «Игра пройдена.», **не выходить автоматически**. Игровой ввод после победы блокируется с подсказкой «Игра пройдена. Доступны: save, history, quit.»

## Тесты

| # | Сценарий | Ожидание |
|---|---|---|
| U-1 | Игровой ввод → `step` | контракт |
| U-2 | `save` | `session.save` вызван, в `step` не ушёл |
| U-3 | `save` при существующем файле, `n` | не сохраняет |
| U-4 | `load` | новая сессия, старый `step` не вызывается |
| U-5 | `load` без сейва | ошибка, текущая сессия цела |
| U-6 | `history` | только `final_text`, без turn-записей |
| U-7 | `quit` | выход, `step` не вызван |
| U-8 | Пустая строка | передана в `step` |
| U-9 | `game_finished=true` | текст показан, «Игра пройдена.», цикл не вышел |
| U-10 | Ввод после победы | `step` не вызван, подсказка |
| U-11 | `aborted=true` | явное сообщение, цикл завершён |
| U-12 | `rung=3` | игнорируется, пометки нет |
| U-13 | `sav` (опечатка) | передано в `step` |
| U-14 | `SAVE` | распознано |

## Известные ограничения

- Один слот сейва. Несколько — расширение контракта.
- Нет подсказок «что можно сделать» — MVP.
- Нет цветов, markdown, форматирования.
